# Welcome to Hash Mark

Hash Mark makes Markdown easy to read and write. Everything stays on this device — no account needed.

## Try the basics

- **Bold**, *italic*, ~~strikethrough~~ and `inline code`
- [Links](https://commonmark.org/help/) and nested lists
  - like this one

## Tasks

- [x] Open Hash Mark
- [ ] Write your first note

## Modes

| Mode | What it's for |
| --- | --- |
| Write | Writing, with formatting as you type |
| Split | Markdown and preview side by side |
| Read | The finished document |

> Tip: switch to Read mode to see the finished document.

console.log('Hello, Markdown');
